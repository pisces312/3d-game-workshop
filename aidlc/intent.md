# Intent — Space Fold《空间折叠》

> AI-DLC 阶段：Inception ｜ 流程记录：`aidlc/spaces/default/intents/261016-space-fold-game/`（express 流程）
> 来源：黑客松任务说明（用户原始提示，下文简称 `[desc]`）

## 1. 项目目标

在 3 小时黑客松内交付一款**可现场演示**的 3D 网页小游戏：

- 玩家控制一颗发光能量球，沿无限延伸的圆形隧道的**圆周**移动；
- 带缺口的霓虹圆环障碍从远处飞来，玩家需让能量球对准缺口穿过；
- 撞上障碍即失败，穿过得分，速度随得分上升；
- **同一套代码**适配桌面键鼠与手机触屏；
- 手机横竖屏切换时，游戏**不中断、不重置、不丢分**。

成功标准（可度量）：

| 编号 | 成功标准 | 判定方式 |
|---|---|---|
| G1 | 从打开页面到开始一局 ≤ 2 次操作（点击开始 / 按空格） | 手动演示 |
| G2 | 一局能完整经历 开始 → 得分 → 失败 → 重开 | 手动演示 + 自动化测试 |
| G3 | 游戏中旋转手机，分数、角度、障碍位置不变 | 自动化测试（Resize 不改世界状态）+ 真机手动 |
| G4 | `npm run test`、`npm run build` 全部通过 | 命令输出 |

## 2. 范围

**范围内（P0，必须交付）**：完整可玩 3D 核心循环、圆周操作、碰撞判定、得分、难度递增、
READY / PLAYING / PAUSED / GAME_OVER 状态机、重开、桌面 + 触屏统一输入、横竖屏无缝切换、页面隐藏自动暂停。

**范围内（P1，尽量交付）**：旋转缺口障碍、隧道/摄像机空间扭曲、尾迹与穿越粒子、撞击闪屏、
WebAudio 合成音效、localStorage 最高分（不可用时降级）、开始界面操作教程、性能自动降级。

**P2（时间不够即砍）**：更多障碍类型、额外美术、额外动画。

## 3. 约束

- 技术栈固定：HTML5 + JavaScript ES Modules + Three.js + Vite + 原生 CSS；测试用 Vitest。
- 不用 React/Vue、后端、数据库、物理引擎、外部模型、付费 API、大贴图、高成本后处理。
- 全部画面由 Three.js 程序化生成。
- 不锁定屏幕方向、不依赖陀螺仪、不通过 reload 适配。
- 时间盒：3 小时；优先级 可玩性 > 横竖屏稳定性 > 操作手感 > 视觉表现 > 额外功能。

## 4. 非目标

- 不做账号、排行榜联网、多人。
- 不做关卡编辑器、皮肤商店。
- 不追求 PC 高画质后处理（Bloom 等）。
- 不承诺未经测量的帧率数字。

## 5. 关键决策（摘要）

| 决策 | 选择 | 理由 |
|---|---|---|
| 摄像机 | 跟随能量球滚转，使球始终位于屏幕下方 | 屏幕上"向右拖 = 球向右"恒成立，控制方向永不反转；隧道旋转天然带来空间扭曲感 |
| 逻辑/渲染 | `Game`（纯逻辑，无 three/DOM）+ `Renderer`（只读状态同步网格） | 可在 Node 中做自动化测试；resize 只碰渲染层 |
| 时间步进 | 固定 1/120 s 步长 + 单帧 0.1 s 上限 + 恢复时重置时钟 | 防漏判、防后台返回时间跳跃 |
| 输入 | 单一 `InputManager`，Pointer Events + 键盘，按 pointerId 跟踪 | 一套代码兼容鼠标/触屏，避免 touch→mouse 重复 |
| 横竖屏 | 只更新 renderer 尺寸、相机 aspect/fov；世界坐标固定 | 满足"世界状态不变" |
