# Scope Document

## In scope

- Single-page 3D stacking gameplay.
- Alternating X/Z movement for airborne blocks.
- Pointer/touch/Space release action.
- Gravity fall, two-axis overlap calculation, clipping to the overlap region.
- Game-over state, restart action, current score, local best score.
- Responsive HUD and mobile input behavior.
- Static-server local run instructions.

## Out of scope

- User accounts or cloud persistence.
- Multiplayer, online leaderboards, monetization.
- Sound, music, skins, level editor, replay system.
- Native app packaging and production deployment.

## Profile decision

Use the AI-DLC `MVP` profile: the result is a real playable first increment, while production operation and deployment are intentionally deferred. [decision]
