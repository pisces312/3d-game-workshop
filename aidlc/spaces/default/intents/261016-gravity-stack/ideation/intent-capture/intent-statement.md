# Intent Statement

## Problem

Players need a simple, readable timing challenge with immediate feedback: align a moving 3D block over the tower and release it at the right moment. [desc]

## Outcome

Deliver a browser game that makes the core loop playable in one page: observe movement, release a block, resolve overlap, and repeat until the tower falls. [desc]

## Target users

Casual players using a desktop browser or a mobile browser for short sessions. [assumption]

## Success signals

- A new player can start a round without setup.
- A release creates visible falling and stacking feedback.
- A failed overlap produces a clear restart path.
- The page works with both pointer input and Space.
