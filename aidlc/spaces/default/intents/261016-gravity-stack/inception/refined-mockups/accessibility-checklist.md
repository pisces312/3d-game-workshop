# Accessibility Checklist

- [x] Start and restart controls are real `<button>` elements.
- [x] Game region has an accessible label.
- [x] Status text uses `aria-live` for state changes.
- [x] Text has high contrast against the dark scene.
- [x] Core action has a keyboard alternative (`Space`).
- [x] Layout has a mobile breakpoint.
- [ ] Add reduced-motion mode for a future release.
- [ ] Add non-color-only visual landing feedback for a future release.
