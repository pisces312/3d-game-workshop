# User Stories

| ID | User story | Acceptance criteria |
| --- | --- | --- |
| US-01 | 作为玩家，我想创建房间并复制房间码，以便邀请伙伴。 | 创建后显示房间码和玩家名单，创建者成为房主。 |
| US-02 | 作为受邀玩家，我想输入房间码加入，以便参与同一局游戏。 | 有效候客房间可加入；不存在、已开局或满员时显示错误。 |
| US-03 | 作为房主，我想开始游戏，以便全员同时进入挑战。 | 只有房主可用开始按钮；房主离开后其他成员之一获得该权限。 |
| US-04 | 作为队友，我想在相同河道中看到大家，以便协作前进。 | 所有成员进入相同关卡及相同木筏布局；能看到远端小羊和名字。 |
| US-05 | 作为玩家，我想使用常见输入控制小羊，以便跨设备游玩。 | 键盘、点击按钮、触控轻点与滑动均可转向或跳跃。 |
| US-06 | 作为玩家，我想看到生命、分数、限时和关卡信息，以便掌握游戏状态。 | HUD 随游戏推进更新；耗尽生命或超时进入规定状态。 |
| US-07 | 作为玩家，我想知道谁先到达并等待队友，以便完成合作目标。 | 完成者获得名次；全员完成才推进；第 3 关全员完成后显示胜利。 |
| US-08 | 作为部署者，我想用一个命令启动服务，以便本地或反代部署。 | `npm start` 可监听默认端口，`PORT=8080 npm start` 可覆盖端口。 |
