# Refined Mockups and Interaction Specification

## Screen states

1. **初始房间页**：昵称输入、房间码输入、创建与加入按钮、连接/错误提示。
2. **候客房间页**：大号房间码、成员名单、房主专属开始按钮；非房主显示等待文案。
3. **游戏页**：全屏 3D 河流、顶部 HUD（关卡/分数/生命/限时）、右侧排行榜、底部方向与跳跃按钮。
4. **等待页**：本玩家抵达后显示名次和等待队友；继续展示成员进度。
5. **胜利/失败页**：展示结果，并提供重新开始或返回房间的下一步操作。

## Interaction rules

- `W/A/S/D`、方向键和屏幕方向按钮仅改变朝向；`Space`、轻点或跳跃按钮执行一次跳跃。
- 手势移动超过阈值时按主要轴改变方向；短触为跳跃。
- 任意文本输入聚焦时，游戏快捷键先失焦，避免干扰姓名和房间码录入。
- 房间错误信息展示在表单下方，错误不应关闭当前界面。
- 排行榜按已完成的名次优先排序，其余成员按名称显示。
