# Requirements — 迭代 3：视觉升级（流程记录 `261016-visual-upgrade`）

## Intent 分析

来源 `[desc3]`：用户希望界面"更 3D、更炫酷"。经结构化问题确认，四个方向全部要做：
- 游戏场景更立体
- 开始 / 结算界面 3D 化
- HUD 与反馈动效
- Bloom 辉光后处理

首版约束继续有效：可玩性 > 横竖屏稳定性 > 操作手感 > 视觉表现；不得为视觉牺牲移动端可用性；视觉缺口必须与碰撞规则一致。

## 功能需求

| REQ | 需求 | 优先级 |
|---|---|---|
| FR24 | 隧道立体化：半透明发光内壁（自定义 shader，沿 z 流动的光带，随速度加快），保留线框环；扭曲阶段内壁变色。 | P0 |
| FR25 | 障碍立体化：环体加厚并带边缘高光层（同弧长的细亮环），旋转障碍保持亮蓝。缺口端面仍是过轴的径向平面，弧长 = 2π − gapSize，与判定一致。 | P0 |
| FR26 | 速度感：速度线（池化 LineSegments，速度越高越长越密）、空间尘埃；FOV 随速度轻微拉伸（≤ +8°），穿越障碍时一次短促镜头冲击。 | P1 |
| FR27 | 菜单 3D 化：READY / PAUSED / GAME_OVER 时背景隧道持续缓慢流动并环绕旋转，Bolt 小橙放大居中展示（只改视觉，不改世界状态）；面板为毛玻璃 + 轻微透视倾斜；标题为多层阴影的 3D 立体字；主按钮带呼吸辉光。 | P1 |
| FR28 | HUD 动效：得分变化时数字弹跳；"Perfect"判定（穿越时 \|Δθ\| ≤ gapSize/4）显示 Perfect 与连续 Perfect 次数（xN）；服务提示从下方飞入。 | P1 |
| FR29 | 撞击反馈：碎裂粒子爆发（复用粒子池，单次 ≤ 40 个）、更强的屏幕震动与色差闪屏（CSS 实现）。 | P1 |
| FR30 | Bloom：使用 three 自带的 EffectComposer + UnrealBloomPass；仅在非触屏设备或 `?bloom=on` 时开启，`?bloom=off` 强制关闭；平均帧时间 > 20 ms 持续 2 s 自动关闭，且只关一次。 | P2（可选增强） |

## 非功能需求

| REQ | 需求 |
|---|---|
| NFR8 | 新增视觉不在每帧分配对象；速度线 ≤ 120 段，粒子池仍为 80。 |
| NFR9 | 视觉层不得修改 `Game` 世界状态；resize 仍只改渲染（T6 保持通过）。 |

## 验收标准

| AC | REQ | 标准 | 测试 |
|---|---|---|---|
| AC20 | FR25 | 障碍主环与高光环的弧长都等于 2π − gapSize，旋转 = gapCenter + gapSize/2。 | T16 自动 |
| AC21 | FR28 | `isPerfect(θ, gapCenter, gapSize)` 在 \|Δθ\| ≤ gapSize/4 时为真，含 0/2π 跨界；连续 Perfect 计数在非 Perfect 或重开时归零。 | T17 自动 |
| AC22 | FR26 | 动态 FOV = 基础 FOV + min(8, k·(speed − 14))，且不超过 MAX_VFOV。 | T18 自动 |
| AC23 | FR30 | Bloom 决策：触屏且无参数 → 关；`?bloom=on` → 开；`?bloom=off` → 关；连续慢帧 → 自动关闭一次。 | T19 自动 |
| AC24 | NFR9 | 菜单动画、FOV、震动、Bloom 开关期间 `game.snapshot()` 不变。 | T20 自动 |
| AC25 | FR24–FR29 | 浏览器中开始页、游戏中、结算页呈现新视觉，控制台无错误；`?debug` 帧率记录在案。 | 浏览器手动 |
| AC26 | 回归 | 现有 87 个测试全部通过，构建成功。 | `npm run test` / `npm run build` |

## 约束

技术栈不变；Bloom 只用 three 包自带的模块，不引入新依赖；不使用图片或字体资源。

## 范围外

阴影、SSAO、景深等其他后处理；新玩法。
