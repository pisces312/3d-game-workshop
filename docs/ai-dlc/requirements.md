# 重力叠叠乐：需求

## 目标

制作一个可在浏览器直接体验的 3D 叠方块小游戏。玩家通过把握移动方块的落点，让方块不断叠高，追求更高层数。

## 用户故事

- 作为玩家，我可以看到一个具有空间感的 3D 方块塔和悬浮方块。
- 作为玩家，我可以点击、触摸或按空格键，让当前方块自由落下。
- 作为玩家，当落点与上一层有重叠时，方块会被裁切到重叠区域并继续游戏。
- 作为玩家，当方块完全错开时，我能看到本局成绩、最高纪录并重新开始。
- 作为玩家，我能在桌面和移动设备上体验相同的核心玩法。

## 验收标准

1. 页面启动后展示 3D 场景、开始入口和操作提示。
2. 游戏开始后，方块在 X/Z 轴交替往返移动。
3. 玩家操作后，方块受重力下落并与塔顶发生判定。
4. 有效落点会按实际重叠尺寸裁切方块，并使层数加一。
5. 完全错开会结束本局，展示本局层数和本地最高纪录。
6. 游戏可响应窗口尺寸变化，触摸不会触发页面滚动或缩放。
7. 项目不需要本地依赖安装即可运行。
